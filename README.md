# 食べ歩きノート v1.0

Android向けの食べ歩き記録PWAの初期実装です。HTML/CSS/JavaScriptで構成し、記録と写真をIndexedDBへ保存します。Visual Studio 2022でフォルダーを開いて編集できます。

## 主な機能

- 訪問日、店名、地域、料理、価格、味、ボリューム、雰囲気、自由メモを登録・編集
- Androidのファイル／写真選択画面から既存画像を選択
- 記録一覧、店名・料理・地域などの検索、投稿状況による絞り込み
- テンプレートからSNS投稿文を生成し、編集・コピー
- 未投稿／投稿準備中／投稿済みの管理
- JSONバックアップの書き出しと復元（写真データも含む）
- PWAのマニフェストとService Workerによるオフラインキャッシュ

## 注意点

1. データはブラウザのIndexedDBに保存されます。同じスマホでも、別ブラウザや別のWebサイトURLでは別の保存領域になります。
2. ブラウザのサイトデータを消去すると記録が消える場合があります。定期的にJSONバックアップを保存してください。
3. JSONバックアップに写真を含めるとファイルサイズが大きくなります。
4. SNSへの直接投稿は行いません。投稿文のコピーと投稿状況管理のみです。
5. 初期版ではデータ同期・クラウド保存・自動通知はありません。
6. PWAとしてインストールするには、HTTPSで配信する必要があります（localhostでの開発時を除く）。
7. アイコン画像は仮のプレースホルダーです。配信前にアプリ用アイコンへ差し替えてください。

## PCでの簡易テスト

Service WorkerやPWA機能を検証するには、`file://` で直接開くのではなく、ローカルHTTPサーバーまたはHTTPSで配信してください。Visual Studioの任意のWebサーバー設定、またはローカルの静的ファイルサーバーを利用します。

開発用の例（Pythonがインストール済みの場合）:
```bash
python -m http.server 8000
```
プロジェクトフォルダーで実行し、PCのブラウザで `http://localhost:8000` を開きます。

## Androidでの導入

1. HTTPS対応の静的ホスティングへフォルダーの中身をアップロードします。
2. AndroidのChromeでURLを開きます。
3. ブラウザメニューから「ホーム画面に追加」または「アプリをインストール」を選択します。
4. 最初にオンラインで開き、必要なファイルがキャッシュされてからオフライン動作を確認します。

## バックアップ形式

アプリの「設定・バックアップ」からJSONファイルを書き出せます。復元時は既存記録を置き換えるため、必要に応じて先にバックアップを作成してください。

## フォルダー構成

- `index.html` : 画面
- `css/style.css` : スマホ向けデザイン
- `js/database.js` : IndexedDB操作
- `js/app.js` : 画面制御、検索、テンプレート、バックアップ
- `manifest.json` : PWA設定
- `service-worker.js` : オフラインキャッシュ
- `icons/` : PWAアイコン（プレースホルダー）
